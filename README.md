# News App 📰

A modern Flutter News Application built using GetX and News API.

## Features ✨
- Latest Headlines
- Detailed News Screen
- News Search
- Text To Speech (TTS)
- Category-wise News
- Profile Page
- Responsive UI
- API Integration
- State Management using GetX

## Tech Stack 🛠
- Flutter
- Dart
- GetX
- REST API
- HTTP 
- Flutter TTS
